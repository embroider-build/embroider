# @embroider/core

A build system for EmberJS applications.

This package holds the Embroider resolver and the core build options. An app installs it as a peer dependency of [`@embroider/vite`](https://github.com/embroider-build/embroider/tree/main/packages/vite) and [`@embroider/compat`](https://github.com/embroider-build/embroider/tree/main/packages/compat).

The options are documented in [Core Options](https://github.com/embroider-build/embroider/blob/main/packages/core/src/options.ts).

See the [top-level README](https://github.com/embroider-build/embroider#readme) for the status of the project.
